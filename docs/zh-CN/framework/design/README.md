# 设计

**其他语言：** [English](../../../en/framework/design/README.md) | [简体中文](README.md)

已定稿的设计记录，一个主题一个文件。

每篇记录覆盖：问题、选定的方案、被考虑过的替代方案。设计是**工作文档**，随实现演进。

设计仍在变动时，草稿可以留在仓库之外；本目录只收**已定稿**的设计。命名见
[`../../repository/documentation/conventions.md`](../../repository/documentation/conventions.md)。
