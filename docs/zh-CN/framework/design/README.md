# 设计

**其他语言：** [English](../../../en/framework/design/README.md) | [简体中文](README.md)

*设计记录*——一个文件一项已定稿的设计。

设计记录解释框架的某一部分，前提是它的做法已经定稿：它解决什么问题、怎么运作、以及塑造了它的取舍是什么。它是写给「读框架的人」的，不是当初讨论过程的日志；设计本身变了，它才跟着改。

这里放：

- 已定稿的设计，一个主题一个文件。

这里不放：

- 仍在变动的设计——那是草稿，留在仓库之外，免得半成品被当成结论；
- 产生某个决策的讨论过程——决策记录不是设计记录，见 [`../../repository/documentation/documentation.md`](../../repository/documentation/documentation.md)；
- 术语与定义——见 [`../reference/glossary.md`](../reference/glossary.md)。
