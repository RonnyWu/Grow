# 参考

**其他语言：** [English](../../../en/framework/reference/README.md) | [简体中文](README.md)

*参考*——用来查，不用来通读。

这里放：

- [`glossary.md`](glossary.md)——文档中每个术语的含义；
- 框架自己定义的查阅表——它的层、它的视图、它的不变式。

文档页面必须遵守的命名规则不属于框架参考；它们在
[`../../repository/documentation/conventions.md`](../../repository/documentation/conventions.md)。

公开 API 参考由源码里的 XML 文档注释生成，**不在这里手写**。
