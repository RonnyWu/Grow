# 指南

**其他语言：** [English](../../../en/repository/guides/README.md) | [简体中文](README.md)

*操作*——贡献者任务，一个任务一页。

这里放：

- 如何打开工程并构建；
- 如何无头运行 EditMode 测试；
- 如何应用格式化闸门（`dotnet format`）；
- 如何发布版本、如何开 Pull Request。

指南是**目标导向**的：给出达成某个结果的步骤，背景知识链到
[`../../framework/reference/`](../../framework/reference/) 或
[`../../framework/architecture/`](../../framework/architecture/)。每一页必须遵守的规则见
[`../documentation/conventions.md`](../documentation/conventions.md)。
