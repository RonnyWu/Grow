# How-to guides

**Task-oriented** — solves a specific problem whose goal you already know.

## Contains

- Single-topic procedures with verb-first titles (`how-0001-add-a-collection.md`).
- Assumes basic background; does not explain the reasoning.

## Does Not Contain

- From-scratch walkthroughs → `../tutorials/`
- Fact lists → `../reference/`
- "Why" discussions → `../explanation/`

## Boundary

How-to answers "how do I"; explanation answers "why this way". The more reasoning a guide
carries, the more it belongs in explanation.
