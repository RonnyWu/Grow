# How-to guides

**任务导向** —— 帮我完成一个具体的、我已经知道目标的任务。

## 收录

- 单主题的实操步骤，标题以动词开头（`add-a-collection.md`）。
- 假设读者已具备基本背景，不解释原理。

## 不收录

- 从零引导 → `../tutorials/`
- 事实清单 → `../reference/`
- "为什么"的讨论 → `../explanation/`

## 边界

How-to 解决"怎么做"；explanation 回答"为什么这么做"。原理讲得越多，越应该挪去 explanation。

## 现状

暂无内容。候选：`run-editmode-tests.md`、`add-a-collection.md`、`add-an-adr.md`。
