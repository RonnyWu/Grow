# Reference

**信息导向** —— 工作过程中需要查阅的确定事实。

## 收录

- 目录结构、命名规则、类型与 API 签名、配置项、枚举值。
- 结构与格式稳定、可被检索、无需按顺序阅读。

## 不收录

- 教学步骤 → `../tutorials/` `../how-to/`
- 决策理由 → `../explanation/` 与 `../architecture/`

## 边界

Reference 服务于"我正在进行的工作"；explanation 服务于"我的理解"。写 reference 时保持中立描述，不要夹带论证。
