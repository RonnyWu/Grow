# Explanation

**理解导向** —— 帮我理解 Grow 为什么这样设计、有哪些取舍。

## 收录

- 架构理由、设计权衡、历史背景、概念澄清。
- 可以按任意顺序阅读，以"为什么"为主线。

## 不收录

- 操作步骤 → `../tutorials/` `../how-to/`
- 可查的事实 → `../reference/`
- 已冻结的单项决策 → `../architecture/`（ADR）

## 边界

Explanation 与 ADR 的区别：ADR 记录**一个具体决策**及其备选；explanation 解释**一整片设计空间**的来龙去脉。ADR 是档案，explanation 是文章。

## 现状

- [`architecture-rationale.md`](architecture-rationale.md) —— 微内核形态、L1 划分、归属判定阶梯等总体理由。
