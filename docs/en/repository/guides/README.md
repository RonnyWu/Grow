# Guides

**Read this in other languages:** [English](README.md) | [简体中文](../../../zh-CN/repository/guides/README.md)

*How-to* — contributor tasks, one page per task.

What belongs here:

- how to open the project and build it;
- how to run the EditMode tests headlessly;
- how to apply the formatting gate (`dotnet format`);
- how to cut a release and how to open a pull request.

A guide is goal-oriented: it gives the steps to reach an outcome, and links to
[`../../framework/reference/`](../../framework/reference/) or
[`../../framework/architecture/`](../../framework/architecture/) for the background. The rules a
page must follow are in
[`../documentation/conventions.md`](../documentation/conventions.md).
