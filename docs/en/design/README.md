# Design

**Read this in other languages:** [English](README.md) | [简体中文](../../zh-CN/design/README.md)

Settled design records, one file per topic.

Each record covers the problem, the chosen approach, and the alternatives that were considered.
A design is a working document: it changes as the implementation evolves.

Drafts may live outside the repository while a design is still moving; this folder holds a design
once it has settled. File naming follows [`../guides/documentation.md`](../guides/documentation.md).
