# Reference

**Read this in other languages:** [English](README.md) | [简体中文](../../../zh-CN/framework/reference/README.md)

*Reference* — facts to look up, not to read end to end.

What belongs here:

- [`glossary.md`](glossary.md) — the meaning of each term used across the documentation;
- look-up tables the framework itself defines — its layers, its views, its invariants.

The naming rules a documentation page must follow are not framework reference; they are in
[`../../repository/documentation/conventions.md`](../../repository/documentation/conventions.md).

The public API reference is generated from the XML documentation comments in the source code; it
is not written by hand here.
