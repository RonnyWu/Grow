# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| Latest `0.1.x` | :white_check_mark: |
| Older | :x: |

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

- Preferred: use GitHub's private vulnerability reporting (repository **Security** tab →
  *Report a vulnerability*).
- Alternative: email the maintainer at `<security contact>`.

We aim to acknowledge a report within a few days, keep you updated on the fix, and credit
you in the release notes unless you prefer otherwise.
