# Contributing

Thanks for your interest in Grow.

## Documentation

Architecture decisions are recorded as ADRs under [`docs/architecture/`](docs/architecture),
named `ADR-NNNN-topic.md` (e.g. `ADR-0001-project-and-packages.md`). Each new decision gets
the next zero-padded four-digit number and a short kebab-case topic.

## Development

This repository is a Unity project. Open it with Unity 2021.3 LTS or later; the package
lives under `Packages/com.ronny.grow`.

## Commits

- Keep commits focused and explain the *why*.
- Follow [Conventional Commits](https://www.conventionalcommits.org/) where possible.
